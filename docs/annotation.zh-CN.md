# tRNA、CDS 注释与完整度判读

NCR1 完整性不再是保留和评估其余序列的前提。`annotate` 新增
`gene_quality.tsv` 和 `records[].gene_quality`，按每个预期基因汇总缺失、
不完整、多个同源位置、CDS 异常及与已提供组装歧义的重叠。
`annotation_clear` 仅表示这些检查未发现问题；注释没有重新验证 reads，
未提供组装歧义文件也不代表没有歧义。NCR1 之外的问题仍需逐项处理，
完整基因组与闭环标记保持原有证据要求。详见 [partial 工作流](partial_results.md)。

本文说明当前 `mitovarr annotate` 的实际实现。**“检出同源基因”“边界完整”“通过当前完整度规则”分别表达不同信息；个别碱基不同不等于基因缺失。** RNA 末端错配仍可能被局部比对裁去，影响完整度分类。

命令示例、全部输出文件和坐标转换见 [annotation.md](annotation.md)，NCR1–4 的位置定义见 [ncr.md](ncr.md)。

组装输出最佳环候选时，可将 `best_circular.fasta` 与匹配的
`best_circular_ambiguity.tsv` 一起交给注释。该序列的环状标记和
`final_verified` 状态会被分别保留；候选已选出不代表重复结构已验证。

## 输入与同源模型

注释在组装候选和选择状态固定之后运行，使用组装 FASTA 和指定物种的模型。内置面板分别来自以下记录，每个面板包含 12 个 CDS、22 个 tRNA 和 2 个 rRNA：

| `--species` | 物种 | 模型来源 |
| --- | --- | --- |
| `cel` | C. elegans | NC_001328.1 |
| `cbr` | C. briggsae | NC_009885.1 |
| `ctro` | C. tropicalis | NC_025756.1 |

每个模型保存一条按转录方向排列的核苷酸序列，也可以通过 `--gene-models` 提供自定义面板。参考坐标不用于强制放置样本基因；注释也不向组装反馈参考序列或补上缺失碱基。

当前方法是核苷酸同源搜索。CDS 定位之后才进行翻译和编码检查，尚无蛋白质同源搜索步骤。tRNA 名称来自同源模型匹配，尚未独立检查反密码子、茎环配对或整体二级结构；报告中的 `rna_structure` 为 `not_assessed`。注释本身不读取 BAM/FASTQ 重新计算支持度。

## 如何找到候选基因

1. 搜索组装序列的正、反两条链。环状输入同时允许基因跨越 FASTA 原点；线性输入不人为连接两端。
2. 使用完全匹配的短序列定位候选区域：tRNA 用 7-mer，CDS/rRNA 用 9-mer。需要多个分布在模型不同位置的种子，不能只靠一个很短的共享片段定位整个基因。
3. 在候选区域执行允许错配和 indel 的 Smith–Waterman 局部比对。分数为匹配 +3、错配 −4、gap 开启 −8、每个后续 gap 碱基 −1；分数不是存在概率或正确率。
4. 合并同一物理位置的重复搜索命中，保留不同位置的拷贝、倒位和部分同源片段。不同基因模型在同一区域发生明显竞争时，保留命中并标记身份不确定。

每个模型、每条链最多搜索 64 个候选起始邻域；触及限制会记录在 `search_limited_models` 中。未检出可能来自缺失、序列过于分化、片段过短或搜索不足，不能仅凭未检出宣称样本发生了基因删除。

## 什么条件算“检出”

成功定位候选后，比对须满足下表条件才进入 `prediction.features`：

| 类型 | 模型覆盖率 | 比对一致率 | 覆盖的模型区间长度 |
| --- | ---: | ---: | ---: |
| tRNA | ≥80% | ≥85% | ≥30 nt |
| CDS | ≥20% | ≥70% | ≥80 nt |
| rRNA | ≥20% | ≥75% | ≥80 nt |

若自定义模型短于表中的长度门槛，区间长度要求改为该模型全长。

- **覆盖率**：比对跨越的模型区间长度／模型全长；内部删除仍包含在这个区间中，不代表每个模型碱基都存在于样本。
- **一致率**：相同的 A/C/G/T 碱基数／比对列数；错配和 gap 均计入分母。

检出门槛允许保留部分同源基因，例如 NCR 内的 ND5 同源残片。达到门槛后，即使完整度分类为 `partial`、`disrupted` 或长度变体，也仍属于检出。CDS 的 20% 门槛只用于发现片段，不能作为完整 CDS 的标准。实现见 [检出与分类代码](../src/annotation/mod.rs)。

## tRNA 的当前完整度规则

一个 tRNA 被赋予 `full_length_supported=true`，当前需要同时满足：

1. 比对覆盖模型的第一个和最后一个碱基。
2. 两端各 8 个比对列中至少 7 个匹配，而且没有 gap。
3. 整体一致率 ≥90%。
4. 样本序列没有 N 等不确定碱基。
5. 整个同源比对没有插入或缺失。
6. 没有与其他 tRNA 模型发生明显的身份竞争。

因此，内部少量 SNP 通常可以通过。两端支持但内部含 indel 时，状态是 `boundary_complete_length_variant`，仍保留基因名称、边界和序列，但不进入当前完整计数。完整且无 gap 的 RNA 同源命中状态为 `complete_homology`；tRNA 一致率在 85% 至不足 90% 时可检出，但不能通过完整度判断。

这是严格的序列同源完整度规则，没有证明 RNA 的结构或功能。特别是“RNA 必须无 indel”以及局部比对的末端裁切会降低完整计数，不能据此改写为“基因不存在”。边界检查见 [比对代码](../src/annotation/align.rs)。

## CDS 的当前完整度规则

CDS 需要两个端点得到支持，再按程序中的线粒体遗传密码表 5 检查实际样本序列：

| 项目 | 当前规则 |
| --- | --- |
| 起始密码子 | `TTG`、`ATT`、`ATC`、`ATA`、`ATG` 或 `GTG` |
| 终止解释 | 完整 `TAA/TAG`；或在已确定边界中，将末端 `T/TA` 标记为需要 polyadenylation |
| 内部终止 | 不允许内部终止密码子 |
| 阅读框 | 每段比对 indel 必须为 3 的倍数，序列末端余数须与终止解释一致 |
| 不确定序列 | 含 N 等不确定碱基不能计为完整 |
| 基因身份 | 不能有明显的其他 CDS 模型身份冲突 |

程序对合法起始位点输出起始 Met；表 5 中的 TGA 按 Trp、AGA/AGG 按 Ser 翻译。末端 `T/TA` 的标记不会向 FASTA 添加 A，也没有检测 RNA 成熟过程。

CDS 还有短末端恢复步骤：局部比对在一端裁掉不超过 9 nt 时，如果样本中对应位置存在、投影边界具有允许的起始或完整终止密码子，且末端 12 nt 至少有 75% 相同，可将注释边界延伸到这些已有碱基，标记为 `orf_inferred`。**当前 RNA 没有这一末端恢复步骤。**

同义替换或普通氨基酸替换一般不阻止完整 CDS 判定；保持阅读框的 3 nt 插入／删除也不必然阻止。导致内部终止或移码的变异会改变编码完整度分类，但命中仍属于已检出基因。编码检查见 [genetic_code.rs](../src/annotation/genetic_code.rs)。

## 输出字段应如何比较

| 字段／状态 | 含义 |
| --- | --- |
| `prediction.features` | 所有达到检出门槛的物理命中，包含部分基因和不同拷贝 |
| `missing_models` | 没有任何达到检出门槛的命中的模型；应读作“未检出” |
| `models_without_full_length_support` | 没有任何通过完整度规则的拷贝；包括已检出但不完整以及未检出的模型 |
| `full_length_supported` | 单个命中是否通过当前完整度规则 |
| `partial` | 当前比对未支持一个或两个端点；可能是真实截短，也可能是末端错配裁切 |
| `boundary_complete_length_variant` | RNA 两端得到支持，但相对模型含 indel |
| `disrupted` | CDS 两端得到支持，但起止密码子、内部终止或阅读框检查未通过 |
| `uncertain_bases` | 原本满足完整规则的命中含不确定碱基 |
| `uncertain_homology` | 原本满足其他完整规则的 tRNA 一致率不足 90% |
| `ambiguous_gene_identity` | 不同同类基因模型在同一位置发生明显竞争 |

`feature_counts` 和 `full_length_counts` 统计物理命中，不是去重后的模型种类数；重复拷贝可能使数量增加。评价模型完整度时，应按模型名称去重，判断每种预期基因是否至少有一个通过完整度规则的拷贝。不能用“22 减去完整 tRNA 数”计算缺失基因数。

解释结果时应并列查看检出、端点支持、序列变异和编码缺陷。RNA 的结构完整性仍是单独的未评估项目。

## RNA 长度变体与末端错配

RNA 的两端都有支持、但内部含 indel 时，当前状态为 `boundary_complete_length_variant`。这类基因已检出，但不计入严格的完整数量；该分类不能直接解释为基因缺失或功能异常。

RNA 末端的单碱基错配可能被局部比对裁去，使命中被标为 `partial`，即使对应的样本碱基仍存在。注释区间缩短不能独立证明组装缺少碱基，应结合样本序列、模型端点和比对范围解释。

RNA 末端错配处理仍需改进。当前实现没有 RNA 结构或功能评估，不能仅凭同源性或完整度标签作出相应结论。

## NCR 长度为零时也必须保留组装歧义

`--assembly-ambiguity` 会把证据关联到短 NCR、零长度 NCR 的两侧连接碱基以及重叠基因的共享碱基。因此，表示候选几何关系的 `annotation_status=adjacent_without_gap`，可以同时具有 `evidence_status=retained_assembly_alternatives`。前者不能当作已经确认的 NCR 缺失。仅位于侧翼基因内部、远离连接处的歧义不会自动归到 NCR。

mapping 局部组装应传入与 `candidate.fasta` 配套的 `structural_ambiguity.tsv`。旋转后的证据保留在 `assembly_ambiguity.tsv`、GFF3 和 JSON 的 `assembly_evidence.ncr_loci` 中；TSV 列格式未改变。

### 不完整 CDS 的终止状态

3′ 边界不受支持时，`cds.stop` 为 `partial_or_uncertain`，片段末尾的 T/TA 不再解释为可经 polyadenylation 补全的终止密码子；末尾完整终止密码子仍保留在翻译证据中。截断造成的不完整末端密码子本身不否定 `frame_valid`，但非三倍数比对缺口仍会否定它。`frame_valid` 不代表基因完整，完整性仍要求两个边界均受支持。
